# 能力边界与证据

本适配使用开发会话在 2026-10-29 可见的 LibTV Remote MCP 工具契约编写。工具 schema、执行准入和模型支持会变化；运行时必须重新检查，本文不是某个模型的永久能力保证。

上游 2026-08 的 CLI 1.0.2 审计仅涵盖特定模型、少量合成参考图和两条视频样本。其参考顺序、固定分辨率/时长、价格预留、CLI 限制和超时行为不能直接外推到 MCP。这里只保留角色/故事板/场景职责分离、检查结果和谨慎恢复等方法。

## 当前可离线验证

- Skill frontmatter、目录发现、Markdown 链接、许可和市场/插件版本一致性。
- 操作说明是否采用实时 schema、真实节点引用、明确授权及稳定幂等恢复。
- 本地 ffmpeg 示例可使用合成色块/静音做烟雾测试，不调用 LibTV 生成。

## 未由静态检查证明

- 任一模型的视觉质量、身份连续性、时长/画幅/声音能力或参考数量上限。
- 实际 OAuth 登录、上传审核、扣费、退款、运行时准入或媒体生成成功。
- 抽样帧之外的连续动作、全片台词与声音质量。

本地终剪是本技能的默认选择，不代表 Remote 没有时间线/编辑/导出能力。用户要求云端交付时查询实时工具并说明限制；不将旧 CLI 的“只会单镜生成”写成平台事实。
