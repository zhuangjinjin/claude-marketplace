# 安全与本地环境

## 授权与审核

图片、视频、音频、clean、返工和升级清晰度均可能收费。仅批准创意或预算评估不代表批准实际生成；用户明确授权的批次不必逐镜重复问同一问题。只读盘点不运行会写节点的准备调用。

审核拒绝时保留错误、任务身份与已确认状态，解释已知原因；未知原因不猜测。引导用户使用平台允许的内容、合法素材或官方申诉渠道，不进行短时付费探针、逐张摘参考/逐句删词来寻找审核漏洞，也不承诺退款。现实人物的肖像、隐私和版权须有适当权限；不在宿主收集身份证或人脸认证材料。不能根据旧 CLI 经验声称所有真人输入必拒。

## 凭据、外发与下载

- 使用当前 MCP OAuth，不读取、复制或保存浏览器 cookie、登录 token、用户凭据文件。连接失效通过 `/mcp` 重新授权。
- 上传真实文件前确认目标画布和用户授权范围。先取得附件字节；文件名、本地路径或聊天附件提示不等于完成上传。
- 上传签名 URL 仅用于工具指定的字节传输，不贴到日志或回答。任务日志不保存不透明上下文凭据。
- 仅下载已核实的产物链接，不把任意用户提供 URL 当作可信内部服务入口。不根据 URL 域名/目录字符串猜测生成成功，检查文件和媒体格式。
- 每次下载使用新建空目录；文件名用本地受控名称，拒绝远端文件名中的路径穿越。不要执行下载目录中的脚本。媒体解析工具需要保持更新；解析失败不更换扩展名伪装成功。
- 不覆盖源文件、旧成片或插件缓存；命令使用独立参数或正确引用路径，不用字符串拼接执行不可信文本。

## 本地依赖

本技能的 LibTV 操作不依赖 CLI。剪辑按需检查 `ffmpeg -version` 和 `ffprobe -version`；缺失时报告并询问安装方式，不自动执行远程安装脚本。不为查看节点安装浏览器、Blender 或钢琴工具。

中文路径使用 UTF-8 文本与参数列表；Windows 示例需针对实际 PowerShell 版本处理，不声称中文路径在所有工具都必然失败。图片若有 EXIF 方向，检查实际显示方向后再决定是否生成转正副本；保留原件。编码能力、字体和滤镜以本机 ffmpeg 构建为准。
