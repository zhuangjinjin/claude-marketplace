# 问题速查

| 现象 | 排查方向 | 处理 |
| --- | --- | --- |
| 工具可见但不准执行 | 当前准入可能变化 | 查 doctor.executionAdmission，暂停新派发，恢复既有任务不换键 |
| 找错同名画布 | 项目/空间/画布层级混淆 | 结合空间与画布 UUID 选择，数字 id 不代替 UUID |
| 模型参数报错 | 旧 schema、错误入口或标识 | 重新读取 get_model，检查创作参数和真实引用；不付费试参数 |
| 生成超时 | 后台可能继续 | 用原 task_id 或原请求/原幂等键恢复，不重建同名节点 |
| 参考没生效 | 提示词有 ID 但没连线 | 核对实际节点引用参数，不能仅手写占位符 |
| 换参考仍串脸 | Ensure 保留了旧边 | 读现有连线，明确 Add/Remove，保留正确资产 |
| 人物换脸/换装 | 多张参考互相冲突 | 逐张看图，区分身份与服装锚点，提出针对性修订 |
| 格线/箭头被拍出 | 分镜有制作标注 | clean 需授权且逐格 QC，不自动重绘 |
| 多人/多物 | 拼图重复或参考污染 | 明确实体数量与各自位置，检查所有输入，不只堆负面词 |
| 道具像浮贴 | 缺尺度/接触/受光 | 提供在场关系；新合成参考需授权 |
| 片段末端漂移 | 动作复杂或镜头时长不适配 | 调整镜头设计，参考实时能力，拆镜须保留剧情并确认 |
| 审核失败 | 原因只能按服务证据判断 | 停止、报告，不做付费二分探针或绕过拒绝 |
| 有 URL 无法交付 | 可能是输入、临时链接或未保存 | 检查结构化输出与 mediaPersistence，再检验本地媒体 |
| 无音轨导致合成失败 | 输入是静音视频 | 先探测，按目标时长补静音或选择纯画面路线 |
| 转场后音画错位 | 各段起点/时长/采样率不同 | 统一 PTS 与规格，音视频对齐到同一段长 |
| 总长不符合预期 | 忘记扣转场重叠或漏镜 | 依据镜头清单核对数量、顺序、重叠和实际输出 |
| 终剪工具缺失 | 本地环境未配置 | 报告依赖，不自动下载执行脚本 |

先完成可只读验证的部分，再决定是否需要修订。重做、续写、高清生成均是新的收费操作，不把质检失败自动转换为重试授权。
