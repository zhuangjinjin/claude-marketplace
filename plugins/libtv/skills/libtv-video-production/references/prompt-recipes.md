# 提示词配方：可选约束，不是模型保证

按镜头需要选模块，避免堆满互相冲突的规则。占位符中的 nodeId 必须替换为实际读取的节点 ID，并接入对应引用参数；由服务端处理编号。不要把历史模型经验当所有模型的硬规则。

## 参考职责模板

- 叙事参考：`{{Node <storyboardNodeId>}}` 仅规定构图、表演与动作顺序，不将格线和标注拍进视频。
- 人物外观：`{{Node <characterNodeId>}}` 规定脸、发型、身形和当前服装；叙事参考里的粗略人脸不替代定版身份。
- 场景布局：`{{Node <sceneNodeId>}}` 规定门窗、通道、家具关系，不要求镜头变成无人环境展示。
- 道具状态：`{{Node <propNodeId>}}` 规定尺寸、形状、握持位置及当前开合/破损状态。

这是语义分工，不是固定槽位。单首帧动画应使用 startFrameNode，不与一般参考列表混用；九宫格不得误当完整首帧输出。

## 按问题选配方

| 问题 | 可用描述与检查 |
| --- | --- |
| 人物漂移 | 指定同一张脸、发型与服装锚点，检查所有参考是否冲突；多人物分别定义身份，不让标签替代真实参考 |
| 人体比例 | 依照人物定版和美术风格描述头身关系，不强制所有人物成年或统一 6.5 头身 |
| 风格混用 | 保持已批准的质感词与材质描述；分镜可以是草图，但成片服从目标风格 |
| 标注入画 | 制作编号、格线、箭头不属于剧情画面；clean 后逐格审查，不删用户要求的剧情文字 |
| 多出人物/物件 | 正面列明主体、数量与空间关系，同时检查参考污染；负面约束是否有效需看具体模型结果 |
| 主体被场景抢走 | 写清叙事主体、动作目的和景别；需要空镜时允许空镜，不能一律禁止环境镜头 |
| 空间漂移 | 列门窗相对位置、运动方向与可见区域；长镜头若超出模型能力，提出拆镜方案而非擅自删动作 |
| 装备丢失 | 指定所属人物、佩戴侧、手持/收纳状态；镜头前后状态一致，切换有明确动作 |
| 换装串色 | 新旧服装参考分开，不把旧全身图误作新服装锚点；说明哪些外观属性保留、哪些改变 |
| 道具贴图感 | 提供道具在场景中的尺度、接触、遮挡和受光关系；必要的合成参考另获授权后制作 |
| 配角抢镜 | 按剧情决定焦点、景深和位置，不用性别或身份一刀切限制正脸/接触 |
| 数量失真 | 对每个实体给出独立位置和状态，检查拼图是否把同一物体表现成多个对象 |
| 环境被做旧 | 指定项目需要的完好程度、年代和材质，不通用地禁止破损 |

## 单镜骨架

1. **目的**：本镜传达什么信息或情绪。
2. **画面**：实际景别、机位、轴线与初始人物位置。
3. **动作**：起始状态 → 一个可执行动作链 → 终态，避免同时执行互斥动作。
4. **参考**：明确每个已连接节点的职责。
5. **连续性**：人物、服装、持物、方向与上一镜/下一镜的衔接。
6. **声音**：说话人、实际台词、画内/画外、音效与配乐；不把提示词标签当对白。
7. **风格**：用户批准的质感描述。
8. **约束**：只加当前镜头必须遵守的条件，不在结尾塞入大量相互抵消的禁令。

现实人物、素材版权与隐私按 [安全说明](content-safety-and-env.md) 处理；不提供通过改词、探针或更换参考绕过审核的配方。
