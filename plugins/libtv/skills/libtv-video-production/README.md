# LibTV MCP 短片制作

把已有剧本、分镜和参考图推进到逐镜生成、质检及成片。改编自 PomeloR611/libtv-video-agent，执行层使用当前 LibTV Remote MCP，而不是原仓库的 CLI。

## 使用

安装或更新父插件 `libtv` 至 1.1.0 并通过 `/mcp` 授权后：

```text
/libtv:libtv-video-production 盘点《逆江湖》“第1集”的资产和现有视频，给出后续镜头方案。只读，不生成、不修改。
```

也可要求“按已确认分镜生成指定的一条视频”或“将已有镜头剪成短片”。只执行用户要求阶段，图片、视频和返工均须明确授权。不会自动跑完整制作、增加备选、重生旧资产或上传本地成片。

## 依赖

- LibTV Remote MCP 连接与用户账号授权，复用父插件配置，不另行安装 CLI。
- 本地剪辑时才需要 ffmpeg / ffprobe；本机缺工具时提示，不自动安装。
- 用户有权使用的图片、人物形象、音频与脚本。上传是外发操作，需在请求范围内。

## 文件

`SKILL.md` 是自动发现入口；`references/` 包含 MCP 契约、制作流程、提示词、终剪、安全、问题速查和能力边界。无需额外全局 AGENTS.md，不修改用户配置。生成日志与媒体保存在用户工作目录，不在插件缓存。

## 验证与许可

仓库根目录 `tests/` 提供离线静态测试与可选 ffmpeg 合成素材烟雾测试；不调用真实付费生成。静态检查不代表画面、OAuth 或云端全链路已验收。
